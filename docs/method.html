Four-coordinate design method

Decode each constraint before choosing the parallel-bar operating point.

The technique is technology-independent: characterize the device, derive the array response, model sensing, and set the conversion range. Their intersection determines the highest useful SNDR.

The four constraint cuboids

Each carries a different technical map.

No coordinate is sufficient alone. A new device changes the values in the model, but the four-part structure stays the same.

01 · Device

Characterize stored conductance.

Measure or specify Gon, Goff, conductance contrast, state variation, read-voltage range, and device energy.

Output: ideal current levels and device-induced spread.
02 · Array

Propagate dimension and parasitics.

Choose local dot-product dimension N, extract line resistance and parasitic conductance, and derive how the current range compresses with position.

Output: array-limited signal separation.
03 · Sensing

Model the analog readout.

Include current-mirror mismatch, bias dependence, current-sensing noise, and any calibration or gain constraints before conversion.

Output: sensed-current distribution width.
04 · ADC

Set the conversion range.

Balance clipping, quantization, and thermal noise using the required precision, reference range, and conversion energy.

Output: total bank-level SNDR and energy.

From parameters to architecture

Use the same six-step technique for every device.

  1. 1

    Characterize

    Collect device and circuit parameters from measurement, compact models, or declared design assumptions.

  2. 2

    Build distributions

    Convert the ideal dot-product levels into current distributions under each non-ideality.

  3. 3

    Sweep coordinates

    Evaluate N, reference voltage, ADC precision, conductance contrast, and sensing conditions.

  4. 4

    Locate maximum SNDR

    Find where reducing one error no longer improves the total because another constraint dominates.

  5. 5

    Validate

    Compare against circuit simulation, silicon measurements, and mapped workload accuracy when available.

  6. 6

    Scale

    Replicate the optimized local bank and combine partial sums digitally to map larger workloads.
